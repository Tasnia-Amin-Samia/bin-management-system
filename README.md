# Bin Management System

**An Academic Project on Efficient Waste Management**

## 1. Project Overview

The Bin Management System is an academic project developed to support efficient and organized waste management. The system focuses on managing bin-related information, monitoring bin status, and improving waste collection processes.

## 2. Project Objectives

1. An automatic waste level detecting working prototype.
2. A fill notification when the bin is 80 percent full.
3. Remote lid control via a smartphone app.
4. Fewer inspections of materials are needed manually.
5.  Cleaner and healthier atmosphere.
6. Future upgrade options like GPS, solar system, and a garbage dumping
alarm system.

## 3. Key Features

- Bin Information Management
- Bin Status Monitoring
- Waste Collection Management
- Organized Record Management

## 4. Requirements

1. ESP8266 NodeMCU Wi-Fi module
2. HC-SR04 ultrasonic sensor
3. SG90 servo motor
4. Mini Breadboard (400 points)
5. Male-male jumper wires and male-female jumper wires
6. Resistors (Three 1k ohm for voltage divider)
7. REMAX power bank (10000mAh, 5V/2.1A output) and micro-USB
cable
8. Plastic bin with cardboard lid for prototype
